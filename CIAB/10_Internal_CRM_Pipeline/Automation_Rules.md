<div class="bluf"><span class="lbl">Bottom line up front</span><br>
Use the Work-Flow engine (the same feature you sell) to automate the repetitive parts of your own sales admin — follow-ups, reminders, trial-onboarding tasks — so the lean team spends time selling and onboarding, not chasing its own to-do list.</div>

## Core automations

| Trigger | Automated action |
|---|---|
| Lead enters "Contacted" | Schedule follow-up sequence (Pack 08 cadence) |
| Demo booked | Reminder + prep checklist to AE |
| Trial started | Kick off 30-day onboarding task chain (Pack 12) |
| Trial day 7 / 21 / 28 | Check-in reminders (protect conversion) |
| Deal won | Handover-to-onboarding + referral-ask task (Pack 07) |
| Deal lost | Prompt to log reason (win/loss learning, Pack 04) |

<div class="callout"><span class="lbl">Automation as leverage</span><br>
For a pod of one to three, automation is what makes the numbers work — it's the difference between an SDR managing 40–60 touches/day (Pack 13) and drowning in manual reminders. It also, again, proves the product's value by living it.</div>

## Implication

These automations are configured once (Pack 10 CRM Setup) and quietly multiply the team's capacity — directly supporting the funnel volumes the model assumes (Pack 08/16).
