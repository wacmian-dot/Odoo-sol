<div class="bluf"><span class="lbl">Bottom line up front</span><br>
One tickable list covering the foundational, gates, commercial-setup and compliance items. Work top-down; the gates (deal + funding + legal) run in parallel with commercial setup so pipeline starts while paperwork completes.</div>

## The checklist

**Gates (resolve early)**
- [ ] Send ten CEO questions; hold reset conversation (Pack 22)
- [ ] Confirm deal structure (Q1) and get it documented (Pack 14)
- [ ] Confirm/deny Polsat (Q6); confirm UK localisation (Q7)
- [ ] Engage solicitor with brief (Pack 14)
- [ ] Start Up Loan application submitted (Pack 17)

**Legal & compliance**
- [ ] UK entity formed (if equity structure)
- [ ] Partnership/agency agreement signed
- [ ] ICO registration + DPA in place (Pack 15)

**Commercial setup (start in parallel)**
- [ ] Own SalesOps CRM instance configured (Pack 10)
- [ ] Confirmed working demo environment (Pack 20)
- [ ] Beachhead target list built (Pack 06)
- [ ] Outreach sequences live (Pack 08)
- [ ] 2–3 vertical demo environments pre-built (Pack 09)

**Ongoing**
- [ ] Weekly/monthly operating rhythm running (Pack 11)
- [ ] KPI dashboard live (Pack 10)

<div class="callout"><span class="lbl">Green means go</span><br>
The commercial-setup items don't wait for the gates — start outreach as soon as the CRM and target list are ready. The only hard prerequisite before <i>signing customers</i> is a confirmed commercial structure and a working, compliant operation.</div>
