<div class="bluf"><span class="lbl">Bottom line up front</span><br>
Month one has two parallel tracks: <b>resolve the gates</b> (send the CEO questions, engage a solicitor, start the Start Up Loan) and <b>start the engine</b> (set up your own CRM instance, build the target list, begin outreach). You can generate pipeline before the deal is fully papered — the free MCS channel doesn't wait.</div>

## The 30-day actions

| Track | Actions |
|---|---|
| **Resolve gates** | Send the ten CEO questions (Pack 22); book the reset conversation; engage a solicitor with the brief (Pack 14); start the Start Up Loan application (Pack 17) |
| **Start the engine** | Set up your own SalesOps CRM instance (Pack 10); build the beachhead target list from MCS + Companies House (Pack 06); begin outreach sequences (Pack 08) |
| **Compliance** | Register with the ICO; put the DPA on the solicitor's list (Pack 15) |
| **Verify** | Confirm a working demo environment; run the localisation questions with RRUP (Pack 20) |

<div class="callout"><span class="lbl">Parallel, not sequential</span><br>
Don't wait for the deal to be signed to start building the market. Outreach, target-list building and CRM setup can begin immediately — so that when the terms are agreed, you already have pipeline moving. This is the fastest path to the first UK reference.</div>

## Implication
Month one turns the package from plan into motion: gates in progress, pipeline starting, compliance underway. It sets up the 90-day plan.
