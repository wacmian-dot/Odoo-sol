<div class="bluf"><span class="lbl">Bottom line up front</span><br>
The UK Start Up Loan is the right first capital: <b>£500–£25,000 per person (up to £100k across partners), 7.5% fixed, 1–5 years, no fee, plus free mentoring.</b> The application narrative writes itself from this package — a proven product, a real growing market, a lean gated plan, and a clear repayment path.</div>

## The loan (verified) ✅

| Term | Detail |
|---|---|
| Amount | £500–£25,000 per person; up to £100,000 across up to 4 partners |
| Rate | 7.5% fixed (from April 2026) |
| Repayment | 1–5 years; no application fee; no early-repayment fee |
| Extras | Free business-plan support + 12 months free mentoring |
| Eligibility | Unsecured personal loan; credit check; UK right to work; trading ≤60 months |

## The narrative spine

1. **The opportunity** — a fast-growing, policy-backed UK renewables-installer market (Pack 03).
2. **The product** — not unproven: 600+ deployments, 15,000+ users (Pack 02).
3. **The edge** — per-seat pricing into a segment incumbents underserve (Pack 04).
4. **The plan** — lean, founder-led, free-lead-channel start; gated spend (Pack 05, 08).
5. **The use of funds** — see Use_Of_Funds.
6. **The repayment** — recurring revenue covers repayment from Year 1–2 base case (Pack 16).

<div class="callout"><span class="lbl">Why this application is strong</span><br>
Start Up Loan assessors look for a credible plan and a realistic repayment path from someone who has done the homework. This package <i>is</i> that homework — verified market data, a proven product, honest risk flags, and a driver-based financial model. Few applicants arrive this prepared.</div>

## Gated element ❓

The exact amount requested depends on the deal structure and cost base (Pack 14/16). Model the amount to cover the cash trough (Pack 16 Cashflow) with margin — likely toward the upper end of the personal limit, or more if a partner co-applies.

## Implication

The Start Up Loan is fast, non-dilutive, and comes with mentoring that sharpens execution. It should be pursued in parallel with the CEO conversation — it does not depend on RRUP.
