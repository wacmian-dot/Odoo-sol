<div class="bluf"><span class="lbl">Bottom line up front</span><br>
Practical rules for daily data handling: collect only what you need, store it securely in the CRM, use it only for its stated purpose, honour opt-outs immediately, and never import third-party proprietary lists. Simple discipline that keeps the operation lawful and trustworthy.</div>

## The rules

| Rule | Practice |
|---|---|
| Minimise | Collect only data needed for the sales/onboarding purpose |
| Secure | Store in the CRM (access-controlled); no loose spreadsheets of personal data |
| Purpose-limit | Use contact data only for the outreach/relationship it was gathered for |
| Honour rights | Action opt-outs and access/erasure requests promptly |
| Clean sourcing | Only lawfully-sourced data; never a prior employer's or partner's proprietary list |
| Retention | Don't keep personal data longer than needed |

<div class="callout"><span class="lbl">The clean-sourcing rule matters most</span><br>
The fastest way to a serious problem is importing a client list you don't have the right to use. Build the prospect list from public registries (Pack 06/08) and lawfully-sourced data only. This protects the operation and, if a team member comes from a competitor, protects them too.</div>

## Implication

This policy operationalises the GDPR baseline (this Pack) into daily habits. It's short by design — a policy nobody reads protects no one.
