<div class="bluf"><span class="lbl">Bottom line up front</span><br>
This is version 2 of the Company-in-a-Box: a consultancy-grade rebuild expanding an earlier 14-document version into 24 Packs (~90 documents), each with a cover, exhibits where analytical, verified sourcing and a professional layout — plus a simulation/red-team pass and a self-healing verification routine.</div>

## Version history

| Version | What it was |
|---|---|
| v1 | 14 single-document folders — correct content, plain presentation |
| **v2 (this)** | 24 Packs, ~90 documents; consultancy-grade production (cover pages, chart exhibits, callouts); analytical frameworks per Pack (TAM/SAM/SOM, Five Forces, unit economics); simulation/red-team layer; self-healing audit |

## What changed in v2
- **Structure:** superseded the flat 14-doc set with the richer Pack structure.
- **Depth:** every analytical Pack applies a named framework and shows at least one exhibit.
- **Rigor:** additional research (market size, competitor pricing/funding, salary benchmarks) folded into the canonical facts; four simulations run.
- **Production:** cover pages, house-style components, charts, sources footers — built to be handed to the CEO.
- **Integrity:** the Polsat claim flagged throughout; the deal structure never asserted; every figure flagged.

<div class="callout"><span class="lbl">What has not changed</span><br>
The discipline is constant across both versions: verified facts, flagged unknowns, nothing overclaimed. v2 is more thorough and better presented — but the honesty standard is the same one that makes the package trustworthy to hand a partner.</div>
